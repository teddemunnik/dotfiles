# Global instructions

Personal instructions loaded into every Claude Code session on every machine, via
`~/.claude/CLAUDE.md` -> `dotfiles/claude/CLAUDE.md`.

Keep this machine-agnostic. Anything true only of one machine (absolute paths, a
work-only toolchain, an employer-specific convention) belongs in that repo's
`.claude/CLAUDE.md` instead, not here.
